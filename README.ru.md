Curcat — программа для извлечения числовых данных из графиков, сканов и снимков экрана. Откалибруйте оси, отметьте кривую вручную или распознайте её автоматически, а затем экспортируйте результат для дальнейшего анализа.

## Возможности

- Декартова и полярная системы координат
- Линейные и логарифмические оси с числовыми значениями или датой и временем
- Ручная расстановка точек и автоматическая трассировка кривой
- Линейная, ступенчатая интерполяция и натуральный кубический сплайн
- Экспорт в CSV, JSON, RON, XLSX, HTML, XML и Markdown
- Сохранение работы в файл проекта
- Интерфейс на русском и английском языках
- Импорт PNG, JPEG, GIF, BMP, TIFF, WebP, ICO, TGA, PNM, HDR, DDS, SVG и SVGZ

## Установка и запуск

### Готовая сборка

1. Откройте страницу [последнего релиза](https://github.com/hexqnt/curcat/releases/latest).
2. Скачайте архив для своей платформы:
   - `linux-x86_64` для 64-битного Linux;
   - `windows-x86_64` для 64-битной Windows;
   - `macos-aarch64` для Mac с процессором Apple silicon.
3. Распакуйте архив и запустите `curcat` (`curcat.exe` в Windows).

В Linux и macOS запустите Curcat из терминала в распакованном каталоге:

```bash
chmod +x curcat # только если при распаковке потерялся признак исполняемого файла
./curcat
```

В Windows дважды щёлкните по `curcat.exe` или запустите его из PowerShell:

```powershell
.\curcat.exe
```

Чтобы сразу открыть изображение, передайте путь к нему при запуске:

```bash
./curcat path/to/chart.png
```

```powershell
.\curcat.exe "C:\path\to\chart.png"
```

### Установка из исходников

Curcat пока требует nightly-версию Rust. Установите [Rust с помощью rustup](https://rustup.rs/), затем выполните:

```bash
rustup toolchain install nightly
cargo +nightly install --git https://github.com/hexqnt/curcat --locked
curcat
```

В Linux для сборки также нужны стандартные пакеты разработки X11/Wayland и OpenGL из вашего дистрибутива.

Чтобы установить программу из локальной копии репозитория:

```bash
git clone https://github.com/hexqnt/curcat.git
cd curcat
cargo +nightly install --path . --locked
```

## Быстрый старт

1. Откройте изображение через диалог выбора файла, перетащите его в окно или вставьте с помощью `Ctrl+V`.
2. Выберите декартову или полярную систему координат и откалибруйте оси по известным значениям на графике.
3. Расставьте точки вдоль кривой или используйте автоматическую трассировку. Чтобы поправить точку или калибровочную линию, перетащите её, удерживая `Shift`.
4. Выберите **Интерполированная кривая** для равномерной выборки или **Исходные точки** для экспорта отмеченных точек без интерполяции.
5. Выберите формат и сохраните данные.

Curcat распознаёт даты в форматах `YYYY-MM-DD`, `YYYY-MM-DD HH:MM[:SS]`, `DD.MM.YYYY`, `YYYY/MM/DD` и других распространённых вариантах.

## Горячие клавиши

| Сочетание                | Действие                                            |
| ------------------------ | --------------------------------------------------- |
| ЛКМ                      | Добавить точку                                      |
| `Shift` + перетаскивание | Переместить ближайшую точку или калибровочную линию |
| Средняя кнопка мыши      | Перемещать изображение                              |
| `Ctrl` + колесо мыши     | Изменить масштаб                                    |
| `Ctrl+O`                 | Открыть изображение                                 |
| `Ctrl+V`                 | Вставить изображение                                |
| `Ctrl+S`                 | Сохранить проект                                    |
| `Ctrl+Shift+P`           | Загрузить проект                                    |
| `Ctrl+B`                 | Показать или скрыть боковую панель                  |
| `Ctrl+Z`                 | Удалить последнюю точку                             |
| `Ctrl+Shift+D`           | Удалить все точки                                   |

Сочетания клавиш для экспорта указаны рядом с соответствующими командами в программе.

## Конфигурация

Curcat работает без файла конфигурации. Чтобы настроить цвета, управление, ограничения экспорта или язык интерфейса, скопируйте и отредактируйте готовый пример [`curcat.toml`](./example_config/curcat.toml). Поместите файл рядом с исполняемым файлом либо в каталог настроек Curcat вашей системы.
